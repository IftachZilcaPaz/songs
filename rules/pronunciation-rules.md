# כללי הגייה שנבדקו באוזן

הכללים האלה נלמדו מתיקונים באוזן של שירים אמיתיים ב-ElevenLabs Music.
הם גוברים על כל כלל אחר כשיש סתירה.

## 1. פנייה בגוף שני: תמיד לנקד לפי המין

המנוע לא יודע אם פונים לזכר או לנקבה, ובלי ניקוד הוא טועה.
בכל פנייה בגוף שני מנקדים את המילה המלאה לפי המין של מי שפונים אליו בשורה:

| נקבה | זכר |
|---|---|
| אַתְ | אַתָה |
| לָךְ | לְךָ |
| אוֹתָךְ | אוֹתְךָ |
| שֶׁלָךְ | שֶׁלְךָ |
| אִתָךְ | אִתְךָ |
| עָלַיִךְ | עָלֶיךָ |
| בִּשְׁבִילֵךְ | בִּשְׁבִילְךָ |
| מִמֵךְ | מִמְךָ |

"את" כמילת יחס (את הבית, את החיוך) נשארת בלי ניקוד.

## 2. פועל עבר בנקבה: הטעמה בהברה האחרונה

היא רצָה (ra-TSA), היא אכְלָה. מנקדים רק את ההברה המוטעמת, כמו בסעיף 4 בכללי הקול.
כשלשתי קריאות יש אותו ניקוד מלא, רק ניקוד ההברה המוטעמת מבדיל ביניהן:
היא רצָה (ra-TSA: היא רצה מרתון) מול הוא רָצה (RA-tsa: הוא רצה עוגה).

## 3. ה' הידיעה, ו-ב/כ בתחילת מילה

- ה' הידיעה מנוקדת בפתח, ואות בּ/כּ/פּ שאחריה דגושה: הַפָּנִים, הַבַּיִת.
- ב' או כ' בתחילת מילה נשמעות קשות (b, k), גם כתחילית: בַּלֵב, וּבַּבַּיִת, כְּמוֹ.

## 4. מילים לועזיות ומאכלים: ניקוד כמעט מלא

ניקוד של ההברה המוטעמת בלבד לא הספיק במילים האלה. מנקדים את כל התנועות, ואפשר להשאיר את ההברה האחרונה בלי ניקוד:
מַרָתוֹן, מַרָתוֹנִים, שַקְשוּקה.

## 5. שמות: ניקוד מלא, בלי דגש באות הראשונה

השם מנוקד בכל התנועות, והטעם במקום הנכון (דַנָה: da-NA). אין דגש באות הראשונה של השם, אלא אם היא בּ/כּ/פּ.

## 6. מילים שהטעם שלהן בהברה הראשונה: לנקד את התנועות

לֶחֶם, נחַת, יֶלֶד, בַּיִת. בלי ניקוד המנוע מטעים אותן בסוף.

## 7. פעלים בהווה ובעתיד: לנקד את הסוף

וּמוֹחֵא, נחַכֶּה, שֶׁתָרוּצִי. בפעלים האלה מנקדים את התנועות שקובעות גוף, מין וזמן.
